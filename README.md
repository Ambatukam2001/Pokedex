Ultimate Pokedex - Platinum Edition
____________________________________________________________________________________________________________________________________________________________
A premium, modernized Pokédex built with HTML5, Tailwind CSS, and JavaScript, designed to deliver a high-performance and visually stunning Pokémon discovery experience.

Key Features
Parallel Pokémon Fetching: Leverages Promise.all for rapid, asynchronous loading of all 151 Gen 1 Pokémon.
Dynamic Type-Centric Design: Cards and detail views dynamically change background color based on the Pokémon's primary type (Grass, Fire, Water, etc.).
Animated Pokémon Sprites: Every Pokémon detail view features high-quality animated GIFs for a more lively experience.
Bottom-Sheet Modal: A sleek, user-friendly detail panel that slides up with tabs for About and Base Stats.
Search and Filter Integration: Real-time searching with a Clear Search feature and alphabetical or numerical sorting.
Iconic Pokéball Entrance: Features a custom-built, full-screen Pokéball opening animation on page load.
Premium Aesthetics: Includes subtle Pokéball watermarks, glassmorphism UI elements, and modern typography.
Technologies Used
Frontend: HTML5, Tailwind CSS, Google Fonts
Logic: Vanilla JavaScript
API: PokeAPI
